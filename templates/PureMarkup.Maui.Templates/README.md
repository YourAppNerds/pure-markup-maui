# PureMarkup.Maui.Templates

`dotnet new` templates for .NET MAUI apps written in C# markup with
[PureMarkup.Maui](https://github.com/YourAppNerds/pure-markup-maui). No XAML files on any platform,
including the Windows host.

```
dotnet new install PureMarkup.Maui.Templates
dotnet new puremarkup-app -n MyApp [--sample-content] [--no-windows] [--applicationId com.example.myapp]
dotnet new puremarkup-page -n SettingsPage -o Pages
```
